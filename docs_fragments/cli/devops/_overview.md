DevOps operations, package management, and system administration.

---

## Usage

```bash
devops [OPTIONS] COMMAND [ARGS]...
```

---

## Commands Overview

| Command | Shortcut | Description |
|---------|----------|-------------|
| `software` | `w` | Install software and manage installer catalogs |
| `repos` | `r` | Manage development repositories |
| `config` | `c` | Configuration management |
| `data` | `d` | Data management |
| `self` | `s` | Self management |
| `network` | `n` | Network management |
| `scripts` | `x` | Run, list, locate, and edit scripts |
| `vault` | `v` | Search and load secrets, manage entries, and access Bitwarden |
| `status` | `S` | Inspect machine, repository, application, and configuration state |
| `security` | `y` | Run security and installer-audit helpers |
